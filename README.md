# ECLIPSE · 마지막 불씨

월식 아래 다섯 구역을 돌파하는 브라우저 2D 로그라이트 액션 플랫포머입니다. 별도 패키지 설치 없이 실행됩니다.

## GitHub 배포와 수정 반영

- 게임: https://malko10.github.io/eclipse-last-ember/
- 소스: https://github.com/malko10/eclipse-last-ember
- 배포 상태: https://github.com/malko10/eclipse-last-ember/actions

`main`에 푸시하면 GitHub Actions가 문법·게임플레이를 검사하고 오프라인 HTML을 생성한 뒤 `dist/`를 GitHub Pages에 배포합니다. 이 작업 폴더의 `origin`은 위 GitHub 저장소입니다. 여기서 게임 수정을 요청하면 검사 후 커밋·푸시까지 진행하도록 `AGENTS.md`에 지침을 기록했습니다. 외부에서 변경한 내용이 있으면 먼저 가져와 통합합니다. 파일 저장만으로 미완성 코드를 푸시하지는 않습니다.

## 실행

로그인 없이 실행하려면 `dist/ECLIPSE-offline.html` 또는 상위 폴더의 `ECLIPSE.html`을 브라우저로 엽니다. 외부 스크립트·모듈·글꼴 없이 동작하는 단일 파일입니다. 변경 후 `node scripts/build-offline.mjs`로 다시 생성합니다.

개발용 소스는 Node.js로 `node server.mjs`를 실행하고 `http://127.0.0.1:4173`에서 확인합니다. `dist/index.html` 자체는 모듈을 사용하므로 HTTP 서버가 필요합니다. 개발 서버의 `/__qa`는 층별 그래픽 점검 페이지로, 배포에는 포함되지 않습니다.

## 조작

| 키 | 동작 |
| --- | --- |
| A / D 또는 ← / → | 이동 |
| Space / W / ↑ | 점프, 공중에서 다시 눌러 2단 점프 |
| J | 직업별 공격, 길게 눌러 연속 공격 |
| Shift | 바라보는 방향으로 무적 대시 |
| K / L | 직업별 스킬 1 / 스킬 2 |
| F | 무기 교체 |
| E | 적 전멸 후 오른쪽 문으로 이동 |
| Esc | 일시정지 / 계속 |
| 1 / 2 / 3 | 직업 또는 유물 선택 |

터치 기기에서는 화면에 조작 버튼이 표시됩니다. 전체 화면과 음소거 버튼은 상단에 있습니다. 플레이 가이드에서 배경음악과 효과음 볼륨을 따로 조절할 수 있습니다.

## 게임 구성

- 검사: 장검·대검, 관절을 움직이는 3연격. 삼연 회오리·무적 돌진 후 여명 가르기
- 궁수: 활·연노. 사냥꾼의 낙인(5초간 받는 피해 +25%)·표식을 우선 조준하는 별무리 폭우
- 마법사: 화염 지팡이·서리 마도서. 빙결의 성좌(동결 후 파쇄)·종말의 유성(폭발 후 잔불)
- 숲·서리 광산·주조장·폭풍 정원·공허 왕좌의 고유 지형, 배경, 날씨와 몬스터 외형
- 층별 공격 패턴과 세 패턴 최종 보스
- 18종 유물, 세 가지 선택지 중 하나를 선택
- 3연격, 점프 버퍼, 코요테 타임, 공중 대시, 검으로 투사체 파괴
- 강타·치명타·처치별 타격 정지와 반동, 충격파, 피해 숫자, 연속 타격 표시
- 다섯 구역의 오리지널 합성 배경음악: 패드·선율·베이스·퍼커션·딜레이. 보스전에서 리듬 강화, 일시정지 시 음악 페이드
- 직업별 스킬 효과음과 저음·노이즈를 겹친 타격음. 오프라인 파일에도 모두 포함
- 브라우저 로컬 저장: 불씨 20개마다 다음 여정 최대 체력 +5 (최대 +30)

진행 기록은 해당 브라우저와 사이트 주소에 저장됩니다. 로컬 미리보기와 배포 사이트의 기록은 서로 별개입니다. 글꼴은 Google Fonts에서 불러오며, 연결되지 않으면 시스템 글꼴로 표시됩니다. 나머지 시각 효과와 사운드는 코드로 생성됩니다.

## 검증

`node --test tests/engine.test.mjs tests/playability.test.mjs tests/expansion.test.mjs tests/combat.test.mjs`

이동, 2단 점프, 대시 무적, 전투 판정, 3직업×5층 진행, 6무기·6스킬, 모든 유물, 장시간 시뮬레이션, 저장 복원을 확인합니다.

`node --test tests/render-offline.test.mjs`는 `@napi-rs/canvas`가 필요합니다. `ECLIPSE_CANVAS_PACKAGE` 환경 변수로 설치 경로를 지정할 수 있으며, 이 작업 환경의 번들 경로가 기본값입니다. 실제 캔버스의 15가지 직업·층 렌더링과 단일 HTML의 시작·스킬·무기 교체·재시작을 저장소 허용/차단 환경에서 검사합니다.

## 파일

- `dist/engine.js`: 게임 상태, 물리, 적 행동, 전투, 성장
- `dist/renderer.js`: 캔버스 배경, 캐릭터, 애니메이션, 이펙트
- `dist/app.js`: 키보드·터치 입력, 메뉴, HUD
- `dist/audio.js`: Web Audio 오리지널 스코어, 스킬·타격음, 음악/효과음 믹서
- `dist/index.html`, `dist/style.css`: 화면 구조와 반응형 UI

`/__audio`는 로컬 전용 오디오 검사 화면입니다. 실제 브라우저의 OfflineAudioContext로 5개 스코어와 효과음을 렌더링하고 무음·클리핑을 검사합니다. 배포에는 포함되지 않습니다. 최신 다운로드 파일은 상위 폴더의 `ECLIPSE-v3.html`입니다.
