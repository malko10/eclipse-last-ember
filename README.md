# ECLIPSE · 마지막 불씨

월식 아래 다섯 구역을 돌파하는 브라우저 2D 로그라이트 액션 플랫포머입니다. 별도 패키지 설치 없이 실행됩니다.

## 실행

Node.js가 있는 환경에서 프로젝트 폴더로 이동한 뒤 `node server.mjs`를 실행하고 `http://127.0.0.1:4173`을 엽니다. 배포용 정적 파일은 `dist/`에 있습니다. ES 모듈을 사용하므로 파일을 더블클릭하는 대신 HTTP 서버를 사용하세요.

## 조작

| 키 | 동작 |
| --- | --- |
| A / D 또는 ← / → | 이동 |
| Space / W / ↑ | 점프, 공중에서 다시 눌러 2단 점프 |
| J | 검 공격, 길게 눌러 연속 공격 |
| Shift | 바라보는 방향으로 무적 대시 |
| E | 적 전멸 후 오른쪽 문으로 이동 |
| Esc | 일시정지 / 계속 |
| 1 / 2 / 3 | 유물 선택 |

터치 기기에서는 화면에 조작 버튼이 표시됩니다. 전체 화면과 효과음 버튼은 상단에 있습니다.

## 게임 구성

- 적 3종, 다섯 구역, 세 가지 공격 패턴의 최종 보스
- 무작위 배치와 10종 유물, 세 가지 선택지 중 하나를 선택
- 3연격, 점프 버퍼, 코요테 타임, 공중 대시, 검으로 투사체 파괴
- 화면 흔들림, 타격 정지, 입자 효과, 합성 효과음
- 브라우저 로컬 저장: 불씨 20개마다 다음 여정 최대 체력 +5 (최대 +30)

진행 기록은 해당 브라우저와 사이트 주소에 저장됩니다. 로컬 미리보기와 배포 사이트의 기록은 서로 별개입니다. 글꼴은 Google Fonts에서 불러오며, 연결되지 않으면 시스템 글꼴로 표시됩니다. 나머지 시각 효과와 사운드는 코드로 생성됩니다.

## 검증

`node --test tests/engine.test.mjs`

이동, 2단 점프, 대시 무적, 전투 판정, 5구역 진행, 모든 유물, 장시간 시뮬레이션, 저장 복원을 확인합니다.

## 파일

- `dist/engine.js`: 게임 상태, 물리, 적 행동, 전투, 성장
- `dist/renderer.js`: 캔버스 배경, 캐릭터, 애니메이션, 이펙트
- `dist/app.js`: 키보드·터치 입력, 메뉴, HUD, Web Audio
- `dist/index.html`, `dist/style.css`: 화면 구조와 반응형 UI
